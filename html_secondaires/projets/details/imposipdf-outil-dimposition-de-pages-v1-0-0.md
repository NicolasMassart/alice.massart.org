# ImposiPDF - outil d'imposition de pages v1.0.0

Octobre 2025

## Description
Outil Python pour imposer les pages d'un PDF en format cahier.

## Première version
Version initiale du projet ImposiPDF, marquant le début de cet outil open-source utile pour les créatifs et les imprimeurs.

## Évolution
Depuis cette première version, l'outil a été considérablement amélioré avec de nouvelles fonctionnalités et une meilleure performance.
